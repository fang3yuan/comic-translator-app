## نظرة عامة

**Comic Translator** تطبيق مكتبي لترجمة صفحات الكوميكس والمانهوا إلى العربية. يساعدك على اكتشاف النصوص في الصفحة، وإزالة النص الأصلي مع محاولة الحفاظ على تفاصيل الخلفية، ثم ترجمة النص وإعادة رسمه داخل مناطق النص.

يعتمد التطبيق على **Google Gemini** للترجمة، ويوفر خيارات متعددة لمعالجة المناطق التي أُزيل منها النص. تختلف السرعة وجودة النتيجة بحسب الصورة والنموذج وإمكانات الجهاز.

## المميزات

- **ترجمة بالذكاء الاصطناعي:** استخدام Google Gemini لترجمة النصوص المكتشفة مع دعم تعليمات إضافية مثل أسماء الشخصيات والنبرة والمصطلحات.
- **ترجمة الصفحة دفعة واحدة:** إرسال النصوص المكتشفة في طلب منظم بدلًا من طلب منفصل لكل مربع نص.
- **إعادة كتابة داخل منطقة النص:** وضع الترجمة في منطقة النص المكتشفة، مع محاولة توسيعها عند توافر مساحة مناسبة.
- **الحفاظ على مظهر الصفحة:** اختيار لون النص وإعادة رسمه بما يتناسب مع النص الأصلي قدر الإمكان.
- **خيارات إزالة النص:** اختيار محرك المسح المتاح، مثل LaMa Manga أو LaMa أو MI-GAN أو OpenCV، بحسب النماذج المثبتة وإعدادات التطبيق.
- **إدارة مفاتيح Gemini:** استخدام مفتاح واحد أو عدة مفاتيح، مع خيارات للنماذج الاحتياطية بحسب الإعدادات المتاحة.
- **سياق السلسلة:** ميزات للمساعدة في اتساق الأسماء والحوار عبر الصفحات، وفق إعدادات الإصدار.
- **واجهة رسومية وأوامر CLI:** استخدام التطبيق من الواجهة أو تشغيل مهام الترجمة من سطر الأوامر.
- **التثبيت على Windows:** يتضمن المستودع ملفات تثبيت وبناء، كما يمكن توفير حزمة جاهزة من صفحة الإصدارات عندما تكون مرفقة بالإصدار.

## البدء السريع

### الخيار الأول: تنزيل نسخة جاهزة

1. افتح [صفحة أحدث إصدار](https://github.com/fang3yuan/comic-translator-app/releases/latest).
2. نزّل ملف التثبيت إذا كان مرفقًا بالإصدار.
3. شغّل المثبّت واتبع التعليمات.

> إذا لم تجد ملف تثبيت ضمن أصول الإصدار، استخدم طريقة التثبيت البديلة أو راجع صفحة الإصدارات لاحقًا. وجود صفحة Release لا يعني بالضرورة أن ملف EXE مرفق بها.

### الخيار الثاني: استخدام ملف التثبيت

يمكن تنزيل المستودع من زر **Code → Download ZIP** في [صفحة المشروع](https://github.com/fang3yuan/comic-translator-app)، ثم تشغيل `Install.bat` على Windows إذا كان الملف متوفرًا في النسخة التي نزّلتها. اتبع التعليمات التي يعرضها الملف، ولا تشغّل ملفات لا تثق بمصدرها.

### الخيار الثالث: التشغيل من المصدر

المتطلبات وخطوات التثبيت قد تختلف حسب نظام التشغيل والإصدار. ابدأ بمراجعة ملفات المشروع الحالية، ثم ثبّت الاعتماديات وشغّل التطبيق:

```bash
pip install -r requirements.txt
python run.py
```

للتأكد من الخيارات المتاحة في سطر الأوامر:

```bash
python run.py cli --help
```

هذه الأوامر مخصصة للتشغيل من المصدر مع إعداد Python مناسب. إذا واجهت مشكلة في تثبيت مكتبة أو نموذج، راجع [المستودع](https://github.com/fang3yuan/comic-translator-app) و[المشكلات المفتوحة](https://github.com/fang3yuan/comic-translator-app/issues).

## إعداد Google Gemini

يحتاج التطبيق إلى مفتاح API صالح لاستخدام الترجمة عبر Gemini.

1. أنشئ مفتاحًا من [Google AI Studio](https://aistudio.google.com/apikey).
2. افتح التطبيق وأدخل المفتاح في قسم الترجمة.
3. استخدم خيار اختبار المفتاح إن كان ظاهرًا في نسختك.
4. راجع حدود الاستخدام وسياسات Google الحالية قبل معالجة عدد كبير من الصفحات.

**حافظ على سرية مفاتيح API.** لا ترفعها إلى GitHub، ولا تضع مفتاحك الشخصي في لقطات الشاشة أو ملفات الإعدادات التي تشاركها.

## سير العمل

```text
صورة الصفحة
    ↓
اكتشاف مناطق النص وقراءة النص (OCR)
    ↓
إزالة النص الأصلي باستخدام محرك المسح المختار
    ↓
ترجمة النصوص باستخدام Gemini
    ↓
رسم الترجمة العربية داخل مناطق النص
    ↓
حفظ الصورة الناتجة
```

قد تحتاج بعض الصفحات إلى مراجعة يدوية؛ فالنصوص الصغيرة أو الخطوط المزخرفة أو الخلفيات المعقدة قد تؤثر في الاكتشاف والمسح والترجمة.

## الأداء والخصوصية

- قد تستغرق إزالة النص وقتًا أطول على الأجهزة ذات الذاكرة المحدودة، خصوصًا عند استخدام نماذج محلية.
- استخدام Gemini يتطلب اتصالًا بالإنترنت، وتُرسل إليه البيانات اللازمة للترجمة وفق طريقة عمل التطبيق.
- لا ترفع صفحات خاصة أو حساسة إلى خدمات خارجية إلا بعد فهم سياسة الخصوصية وشروط الخدمة الخاصة بها.
- جودة المسح ليست مضمونة لكل صورة؛ راجع الناتج قبل نشره أو استخدامه.

## حل المشكلات

- **فشل الترجمة:** تحقق من المفتاح والاتصال بالإنترنت وحدود استخدام Gemini.
- **بطء إزالة النص:** جرّب محرك مسح أخف متاحًا في التطبيق، وأغلق البرامج الأخرى، وقلّل حجم الصور عند الحاجة.
- **نصوص لم تُكتشف أو تُترجم بصورة صحيحة:** جرّب صورة أوضح وراجع مناطق النص والناتج النهائي.
- **مشكلة في التشغيل أو التثبيت:** أرفق رسالة الخطأ وسجل التشغيل عند فتح [بلاغ مشكلة](https://github.com/fang3yuan/comic-translator-app/issues).

## المساهمة والإبلاغ عن الأخطاء

المساهمات وتقارير الأخطاء مرحب بها. عند الإبلاغ عن مشكلة، اذكر نظام التشغيل، وطريقة التثبيت، والخطوات التي أدت إلى المشكلة، ورسالة الخطأ. لا ترفق مفاتيح API أو بيانات شخصية.
