## 🔴 فشلت الترجمة

1. افتح تبويب **Translation** واضغط **Test my keys**.
2. يظهر لكل مفتاح ✔ أو ✘ مع السبب.

![اختبار المفاتيح](images/09b-test-translation-error.png)

| الرسالة | المعنى | الحل |
|---------|--------|------|
| No Gemini API key | لا مفتاح | الصق مفتاحًا في تبويب Translation ([GEMINI.md](GEMINI.md)) |
| invalid key / HTTP 400/403 | المفتاح خاطئ أو بلا صلاحية | انسخه كاملًا من aistudio.google.com/apikey |
| 429 / quota | تجاوزت الحد المجاني | انتظر، أو أضف مفاتيح من مشاريع أخرى. حد اليوم يتجدد بعد 24 ساعة |
| لا يوجد اتصال | إنترنت أو VPN أو جدار ناري | جرّب إطفاء الـVPN |
| مشكلة شهادة SSL | وقت الجهاز خاطئ أو مضاد فيروسات | صحّح التاريخ والوقت |
| model not found | الموديل غير متاح لحسابك | اكتب `gemini-2.5-flash` في خانة Model |
| blocked prompt | جوجل منعت المحتوى | قسّم العمل أو جرّب صفحة أخرى |

**كيف يتصرف البرنامج وحده؟** يرسل الصفحة في طلب واحد، يبدّل المفتاح عند الحد، ينتقل لموديل احتياطي إن لم يوجد الأول، ويعيد طلب أي رقم ناقص من الجواب فقط.

## 🐢 البرنامج بطيء أو يضغط الجهاز

| السبب | الحل |
|-------|------|
| أول تشغيل (تحميل النماذج) | طبيعي، الصفحات التالية أسرع |
| جهاز ضعيف | البرنامج يعمل بأولوية منخفضة وبنصف الأنوية تقريبًا لـLaMa؛ شغّل `inpainting.backend` على `telea` في `config/settings.json` لمسح أخف |
| صور ضخمة جدًا | صغّر الصور قبل الترجمة |
| وضع توفير الطاقة | وصّل الشاحن |

الترجمة نفسها لا تُثقل الجهاز: طلب واحد للصفحة، بفاصل ثانية.

---

## 📐 الخط صغير أو النص خارج الفقاعة

- البرنامج **لا يخمّن الفقاعة**؛ يكتب في مربع النص المكتشف ويوسّعه فقط داخل مساحة فارغة مؤكدة.
- الخط صغير؟ المربع الأصلي ضيّق والترجمة أطول. اختصرها من **Blocks** ثم **Apply Edit**، أو كبّر المربع بسحب زواياه (الحد الأقصى للخط يتبع حجم الأصل).
- فعّل **Shorten Arabic to fit the text box**، وأضف في التعليمات: «ترجمة مختصرة جدًا».

## 🧽 المسح يترك أثرًا

| الحالة | الحل |
|--------|------|
| بقع على خلفية معقدة | نزّل نموذج LaMa من نافذة **Setup** (يعطي أفضل نتيجة) |
| بقي جزء من حرف | زد تمدّد القناع: `detector.mask_dilate` في `config/settings.json` (مثلًا 5) |
| مُسح نص لا تريده مسحه | في تبويب **Blocks** أطفئ **Block enabled** لتلك الكتلة |

---

## 🖱️ السحب والإفلات لا يعمل

1. افتح **Setup** وتأكد أن **Drag & drop support** عليه ✔.
2. أغلق البرنامج وافتحه من جديد.
3. على لينكس قد لا يعمل مع بعض أنظمة النوافذ: استخدم **Add Images**.

---

## 🚫 لا يفتح البرنامج

| الرسالة | الحل |
|---------|------|
| Python was not found | ثبّت بايثون وفعّل **Add to PATH** ثم أعد التشغيل |
| بايثون بلا Tk | أوبونتو: `sudo apt install python3-tk` · فيدورا: `sudo dnf install python3-tkinter` · ماك: `brew install python-tk` |
| فشل تثبيت المكتبات | تحقق من الإنترنت، ثم احذف مجلد `.venv` وشغّل `Start.bat` ثانية |
| النافذة السوداء تُغلق فورًا | افتح CMD داخل المجلد واكتب `Start.bat` لترى الرسالة |

---

## 🔍 لم يقرأ بعض النصوص

- النصوص الصغيرة جدًا أو المزخرفة قد لا تُقرأ. كبّر الصورة قبل الترجمة.
- أضف الكتلة يدويًا: انسخ النص وعدّل أقرب كتلة من تبويب **Blocks**.
- النصوص العمودية واليابانية خارج نطاق هذا الإصدار (إنجليزي فقط).

---

## 📨 ما زالت المشكلة؟

أرسل لقطة للرسالة في أسفل النافذة (السجل)، ونتيجة زر **Test my keys** (المفاتيح مخفية)، ونظام التشغيل.
